# Agent Instructions for This Repo

## What this is

Fork of vineethtrv/wordle-helper: a static web page that filters Wordle candidates from colored guess tiles and ranks the best next guess. Covers all 14,855 valid words in three likelihood tiers. Deployed from `main` to https://onionviolet.github.io/wordle-helper/ via GitHub Pages. The project is landed and stable.

## Stack and commands

Plain HTML, CSS and ES modules, no build step.

- Test: `node test/logic.test.mjs` (25 tests expected).
- Run: open `index.html` through a local static server (module imports need http, not file://).
- Rebuild word data: `python3 tools/build_data.py WORDS.txt COUNT_1W.txt` (sources named in the script header).
- Search runs in `worker.js` so the page stays responsive.

## Conventions

- Assets and imports carry a version query (`?v=10`). When changing `app.js`, `logic.js`, `data.js`, `styles.css` or `worker.js`, bump it everywhere (including inside `worker.js` imports) or browsers mix old and new files.
- Filtering replays Wordle's own scoring, so repeated letters must stay correct. Add a test in `test/logic.test.mjs` for any filter change.

## Where things live

- `logic.js`: filtering and ranking. `app.js`: UI. `data.js`: generated word list, do not hand-edit.
- `README.md`: features. `docs/RECONCILE_2026-11-26.md`: ledger.

## Done means

`node test/logic.test.mjs` passes. For deployed changes, compare the live page after Pages builds (hash or open it). Pushing to `main` deploys, so it needs Weibao's yes.

## See it

Serve locally, enter a guess, tap tiles to color them, and confirm the candidate list shrinks and suggestions update. Check a phone-width viewport too.
